# E-Commerce Product Customization Studio

A full-stack Next.js e-commerce store where users can customize products (text, colors, sizes) and see prices update in real-time.

## Features
- Product Catalogue (Server Components)
- Real-time Customization Preview
- Text & Color Personalization
- Size Selection with Dynamic Pricing
- Shopping Cart with Session Persistence
- PostgreSQL Cart Storage
- Automated Pricing Tests (Vitest)

## Tech Stack
- Framework: Next.js 16 (App Router, Turbopack)
- Language: TypeScript
- Styling: Tailwind CSS
- Database: PostgreSQL (via Docker)
- Testing: Vitest
